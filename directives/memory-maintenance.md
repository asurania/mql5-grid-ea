# Memory Maintenance

## Goal

Keep long-term memory concise and useful while preserving raw history in daily logs.

## Workflow

1. Review recent files in `memory/`
2. Distill durable facts, decisions, and preferences into `MEMORY.md`
3. Move broader reflections or summaries into `second-brain/journal/` or `second-brain/concepts/`
4. Remove stale or redundant items from `MEMORY.md`
5. Keep links current with wiki-links where useful

## Notes

- `MEMORY.md` is curated, not exhaustive
- Daily files can stay messy
- Prefer short, high-signal entries
- Add links to [[MEMORY]], [[OpenClaw Memory System]], and related notes when they make retrieval easier
