# Second Brain

This folder is the structured knowledge base for the OpenClaw workspace.

## Structure

- `journal/` for daily or session summaries
- `concepts/` for evergreen notes and important ideas
- `documents/` for longer-form plans, references, and working docs

## Linking

Use Obsidian wiki-links like `[[MEMORY]]`, `[[USER]]`, and `[[2026-04-12]]` to create graph connections.
